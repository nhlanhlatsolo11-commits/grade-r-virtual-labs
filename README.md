# 🇿🇦 Grade R Virtual Labs

> Interactive STEM learning platform for South African Grade R students - making early childhood education engaging, accessible, and fun.

## 🎯 Launch-ready features

- Playful Grade R design with bright, child-friendly colors and large touch targets
- Moving interactive learning elements and friendly animated feedback
- Voice prompts using browser speech so the app speaks to learners
- Voice commands such as "play", "pause", "math", "science", and "creative"
- Built-in music loop inspired by nursery rhymes for a cheerful classroom feel
- Mobile-first layout for tablets and classroom devices
- Works as a lightweight static app without extra dependencies

## 🚀 How to run locally

```bash
git clone https://github.com/nhlanhlatsolo11-commits/grade-r-virtual-labs.git
cd grade-r-virtual-labs
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## 🎓 Included learning activities

- Science: color mixing, floating and sinking, magnetic objects
- Math: number jump, shape sorter, counting game
- Creative: drawing canvas, pattern maker, music maker

## 📌 Notes

- Browser speech features work best in Chrome and Edge.
- Voice recognition is automatic where supported by the browser, and falls back gracefully.
- Background music is generated in-browser so the app remains easy to launch without external audio files.
