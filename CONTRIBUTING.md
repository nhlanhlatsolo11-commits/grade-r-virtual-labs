# Contributing to Grade R Virtual Labs

Thank you for your interest in contributing! We welcome all kinds of contributions.

## Getting Started

1. **Fork** the repository
2. **Clone** your fork: `git clone https://github.com/YOUR-USERNAME/grade-r-virtual-labs.git`
3. **Create** a branch: `git checkout -b feature/your-feature`
4. **Make** your changes
5. **Commit**: `git commit -m "Add: description of changes"`
6. **Push**: `git push origin feature/your-feature`
7. **Open** a Pull Request

## Types of Contributions

### 🐛 Bug Reports
- Open a GitHub Issue
- Describe the problem clearly
- Include device/browser info
- Provide steps to reproduce

### ✨ New Features
- Check existing issues first
- Describe your idea
- Get feedback before implementing
- Follow code style guide

### 🎨 Improvements
- UI/UX enhancements
- Documentation updates
- Performance optimizations
- Accessibility improvements

### 🌍 Translations
- Add support for new languages
- Create a new module following existing pattern
- Test thoroughly

## Code Guidelines

### HTML
- Use semantic HTML5 elements
- Include comments for complex sections
- Keep indentation consistent (2 spaces)

### CSS
- Use flexbox/grid for layouts
- Keep media queries at the bottom
- Group related styles together
- Use descriptive class names

### JavaScript
- Use clear, descriptive variable names
- Add comments for complex logic
- Keep functions small and focused
- Test on mobile devices

## Testing Checklist

- [ ] Works on Chrome
- [ ] Works on Firefox
- [ ] Works on Safari/iOS
- [ ] Works on mobile devices
- [ ] Works in offline mode
- [ ] Responsive design (360px - 2560px)
- [ ] Touch input works
- [ ] No console errors

## Adding a New Module

1. Add card to dashboard grid in `index.html`
2. Add simulation logic in `openSim()` function
3. Style with existing CSS classes
4. Test thoroughly
5. Update README if needed

## Pull Request Process

1. Update documentation if needed
2. Follow commit message format: `Add: description` or `Fix: description`
3. Reference any related issues: `Fixes #123`
4. Describe changes clearly
5. Be responsive to feedback

## Code of Conduct

- Be respectful and inclusive
- No harassment or discrimination
- Focus on learning and growth
- Help others learn
